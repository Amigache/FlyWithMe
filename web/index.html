🛸 FlyWithMe · Web flasher

Flash the flight firmware onto your board directly from the browser.

Before you start

  • This flasher installs the flight profile only. The bench/SITL image is not published here.
  • Read the manual. FlyWithMe does not replace the pilot or the autopilot failsafes.
  • Connect the LoRa antennas before powering the board. Close any serial monitor using the port.
  • Requires desktop Chrome or Edge, an HTTPS connection and a USB data cable.

1 · Choose your board

Pick the board you have. Picking the wrong one installs a firmware whose pin map does not match your hardware: the board boots but the radio stays mute, with no error.

Beta board. This pin map has been verified against the vendor schematic but not yet tested on physical hardware. Expect problems, and please report what you see — success or failure — at the issue tracker. If the board boots but the radio never links, that is exactly the feedback we need.

2 · Install the firmware

Press the button, select the board's port and wait for it to finish. The NVS (role, parameters and netid) is preserved when updating.

Your browser does not support Web Serial. Use desktop Chrome or Edge. This page must be opened over HTTPS.

3 · Assign the role

A new board stays Disabled until you assign its role: assign Leader to the leader aircraft's board and Follower to the follower's. The change is only accepted on the ground; if the board already has an active role, it needs the FC connected, disarmed and on the ground.

Press “Assign role” and select the board's port.

Verification and files

Binaries and their SHA-256 sums are in firmware/<board>/SHA256SUMS. After installing, the board prints FWM_ID ap_mac=… ap_ssid="FWM XXXXXX" role=… sysid=… band=… on serial at 57600 baud; it also answers to FWM ID.

Security: the factory WiFi password (12345678) is public and identical on every board. It can be used as-is, but we recommend changing it from the “WiFi password” section of the board's WebUI. See the security audit.
